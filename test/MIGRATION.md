# Test migration ledger / 回归迁移逐组账

The regression suite this repository ships was migrated from the private codebase it was
extracted from, at baseline commit `e2f32279`, file `scripts/test/sentinel-quota.test.sh`
(4407 lines, 102 case groups, sha256 `0a06209ffe1e...`). Not all 102 groups came across.
本仓的回归套件迁移自它被抽取出来的那个私有代码库，基线 `e2f32279`，文件
`scripts/test/sentinel-quota.test.sh`（4407 行、102 个用例组）。102 组没有全部搬过来。

**This file exists because a missing test looks exactly like a test that was never
needed.** Without a per-group account, "the suite has 59 groups, upstream had 102" reads
as "the other 43 were environment-specific" — and some of them were not. Every one of the
102 is listed below with what happened to it and why.
**这份文件存在的理由是：一条缺失的用例，和一条本来就不需要的用例，长得一模一样。**
没有逐组交代，「本仓 59 组、上游 102 组」会被读成「另外 43 组本来就是那套环境专有的」——
而其中有一部分不是。下面 102 组一条不落，各自写明去向与理由。

🔴 **The row that matters most is `排除·可改造未做` (10 groups).** Those assert invariants
that have nothing to do with the environment this came from — at-most-once, persist the
ledger before the irreversible action, ABA generations, a state machine that must not
advance on partial failure, positive proof rather than absence-of-negative. They are
excluded here only because the subsystem they happen to be written against (the
resume-delivery chain) was not extracted. **If they are ever silently dropped from this
list, the loss of those invariant families becomes invisible.**
🔴 **最该看的一行是「排除·可改造未做」（10 组）。** 它们断言的不变量与那套环境无关——
at-most-once、先记账再做不可撤回动作、ABA 代际、状态机不得因部分失败而前进、正向证明而不是
「负证据」。它们被排除，只是因为它们恰好写在一个未抽取的子系统（复工投递链）上。
**这一行一旦从清单里悄悄消失，那几族不变量的丢失就再也看不见了。**
